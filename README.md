The funniest cat voicemail greeting: Pickles the cat has knocked your phone off the table and taken over the voicemail. A single deterministic 116-character greeting, written by `main.ts` using only the Deno standard library — no dependencies, no randomness, the same greeting every time.

## The greeting

> "Hi, it's Pickles. I knocked your phone off the table, so this is my voicemail now. Beep, then talk — I'm in the box."

Exactly 116 characters — short, punchy, and unmistakably a cat who has seized the phone.

## Run it

```sh
deno run main.ts
```
