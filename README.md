A cat's voicemail greeting — one line, 116 characters — written by a program
for make.fun's "Funniest Cat Voicemail Greeting" bounty. Pickles knocked the
phone off the table, so this is his voicemail now.

## The greeting

> Hi, it's Pickles. I knocked your phone off the table, so this is my
> voicemail now. Beep, then talk — I'm in the box.

## How it runs

`main.ts` (Node 22, standard library only) writes the greeting to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no
trailing newline, so the file holds exactly the 116-character greeting.
Deterministic: no clock, no randomness, no network, no model calls — both
runs write identical output.

```sh
node main.ts
```

## Why this line

It reads as a voicemail greeting recorded by a cat, in the cat's own voice:
Pickles knocked the phone off the table and claimed the voicemail for
himself, then went back to the box. The joke is specific to cats, it works
spoken aloud in a few seconds, and the punch arrives fast.
